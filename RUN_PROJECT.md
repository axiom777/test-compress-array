# Запуск проекта

## Требования

Для работы проекта необходимо установить:
- Node.js (версия 16 или выше)
- npm или yarn

## Установка зависимостей

Выполните следующую команду в корневой директории проекта:

```bash
npm install
```

## Запуск проекта

### Режим разработки

Для запуска локального сервера разработки выполните:

```bash
npm run dev
```

После запуска откройте браузер по адресу, указанному в терминале (обычно `http://localhost:5173`).

### Сборка для продакшена

Для создания оптимизированной сборки выполните:

```bash
npm run build
```

Результат сборки будет находиться в папке `dist`.

### Предпросмотр сборки

Для предварительного просмотра собранного проекта:

```bash
npm run preview
```

## Запуск тестов

Для выполнения тестов используйте:

```bash
npm test
```

## Структура проекта

```
arrayCompressor/
├── src/
│   ├── arrayCompressor.ts  # Основной модуль сжатия
│   ├── main.ts             # Точка входа приложения
│   └── styles.css          # Стили приложения

│   └── arrayCompressor.test.ts  # Тесты для модуля сжатия
├── public/                 # Статические файлы

├── package.json           # Зависимости проекта
├── tsconfig.json          # Конфигурация TypeScript
├── vite.config.ts         # Конфигурация Vite
```

## Доступные скрипты

В `package.json` доступны следующие команды:

- `npm run dev` - Запуск сервера разработки
- `npm run build` - Сборка проекта
- `npm run preview` - Предпросмотр сборки
- `npm test` - Запуск тестов

## Возможные проблемы

### Ошибка при установке зависимостей

Если при выполнении `npm install` возникли ошибки, попробуйте:

```bash
npm cache clean --force
npm install
```

### Проблемы с портами

Если порт 5173 уже занят, Vite автоматически выберет свободный порт. Адрес будет указан в терминале.

### Ошибки TypeScript

При возникновении ошибок TypeScript убедитесь, что установлены все типы:

```bash
npm install --save-dev @types/node @types/jest
```
